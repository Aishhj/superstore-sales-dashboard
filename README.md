# superstore-sales-dashboard
📁 Dataset
Original Dataset: Sample - Superstore.csv
This is a publicly available dataset from Kaggle and Tableau, containing sales records across various regions, segments, categories, and time periods.

Cleaned Dataset (if any):
If any cleaning or preprocessing was done (e.g., in Excel or Python), the cleaned file is included as well.

🧠 Objective
To explore and visualize Superstore sales data using Tableau and extract key business insights through compelling visual storytelling.

📌 Key Visualizations
This project includes the following dashboards:

Sales Over Time
→ Shows yearly sales growth trend (2014–2017)

Profit by Category
→ Compares how much profit is generated by different product categories

Sales by Segment
→ Identifies which customer segments contribute the most to revenue

Sales by Region/State
→ Geographical heat map showing where sales are strongest

Discount vs Profit (Optional)
→ Highlights how heavy discounts impact profitability

🧾 Tools Used
Tableau Public for dashboard creation

(Optional) Python / Excel for data cleaning

📷 Outputs
Final dashboard screenshot(s) are included in the /output/ or root directory

Insights added using text boxes in the dashboard

(Optional) PDF export or story view if created

🔍 Insights Summary
Technology is the most profitable category

Corporate segment contributes the highest sales

Furniture has low or negative profit margins

Sales grew steadily year over year

California and New York are top-performing states
